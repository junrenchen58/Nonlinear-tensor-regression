# MATLAB Code for  
## *Low-Rank Tensor Estimation from Nonlinear Observations: A Unified Framework*

**Authors:** Junren Chen, Lijun Ding, Dong Xia, and Ming Yuan  
**Contact:** jc6315@columbia.edu

This repository contains the MATLAB code for the numerical experiments in the paper.

- `RAIC_tensor_three_simulations`: experiments for tensor single-index models, ReLU regression, and one-bit tensor sensing.
- `TPR_hyperspectral`: hyperspectral-data experiment for tensor phase retrieval.

Parts of the code were developed with the assistance of ChatGPT (GPT-5.6).
